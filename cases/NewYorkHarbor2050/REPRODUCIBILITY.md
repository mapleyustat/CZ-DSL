# Reproducibility - New York Harbor CZ-DSL case study

Every number, figure and table in the case study is regenerated by the
scripts below from the raw inputs in `data/webdata/`. No value is entered
by hand, and no result is tuned to a target.

## How to reproduce

```bash
python3 tools/nyh_case/run_all.py          # run the full pipeline
python3 tools/nyh_case/run_all.py --check  # verify hashes only
```

## Pipeline

| step | purpose |
|---|---|
| `tools/nyh_case/s1_water_levels.py` | water levels from CO-OPS / PSMSL / CoDEC / altimetry |
| `tools/nyh_case/s2_inundation.py` | connectivity-aware inundation from DEM + return levels |
| `tools/nyh_case/s3_exposure.py` | habitat / population / EEZ exposure |
| `tools/nyh_case/s4_scenario.py` | emit, validate and compile the single .cz |
| `tools/nyh_case/s5_benchmark.py` | query, retrieval, reorganisation, analysis benchmark |
| `tools/nyh_case/s6_validation.py` | cross-validation, bootstrap uncertainty, sensitivity, GSW agreement |

Mode: `full`  |  wall clock: 11.2 s  |  python: 3.12.9

## Method notes

- **Vertical datum.** CO-OPS reports `highest` and `MSL` in the same
  station datum, which is not the geoid used by the DEM. All water levels
  are therefore expressed as anomalies `highest - MSL` from the same
  table, which removes the datum entirely and makes them directly
  comparable with the Copernicus DEM.
- **Sea-level rise.** Projected from observed local trends (PSMSL The
  Battery and Sandy Hook, and the CO-OPS MHHW trend), not from a
  prescribed scenario. Three cases (conservative / central / upper) are
  reported so the spread is visible.
- **Inundation.** Connectivity-aware: a cell below the water level is
  flooded only if a 4-connected path at or below that level reaches the
  open sea. Land/water is taken from the Copernicus convention
  (elevation <= 0 is open water) and independently cross-checked against
  the JRC Global Surface Water occurrence layer.
- **Population.** The flooded mask is aggregated onto the source GHSL
  grid before multiplying by population, so the population field is never
  resampled and the total is preserved.
- **Unused inputs.** The IPCC AR6 regional projection archive in
  `data/webdata/raw/timeseries/sea_level/` is truncated (no end-of-central-
  directory record) and is therefore not used. The CoDEC and GTSR surge
  layers are used; GTSR is declared in the scenario but does not enter the
  central estimate.
