# CZ-Coastal-16 --- analysis dependencies
#
# Acquisition and verification (data/fetch_and_verify.py, data/verify.py) need
# only the Python standard library and are deliberately not listed here, so a
# reader can check the bytes of the release before installing anything.
#
# The versions below are the ones the release was built and checked against.
# `reproduce_analysis.py` needs all of them; each figure script needs numpy and
# matplotlib, and the figure QA tools additionally need PyMuPDF.
#
# `cartopy` is imported at module level by docs/figures/make_fig_essd.py, which is
# the "shared figures" stage. A module-level import always runs, so a reader
# without cartopy does not get a degraded figure: the stage raises ImportError and
# every later stage is skipped. It is therefore a hard dependency, not an optional
# accelerator.
