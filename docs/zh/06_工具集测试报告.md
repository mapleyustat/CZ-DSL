## 7 缺陷与限制

### 7.1 已知限制

| 编号 | 工具 | 限制描述 | 影响程度 |
|:---|:---|:---|:---:|
| L-01 | validator | 行级解析器不支持跨行表达式（如多行字符串拼接），可能漏检部分语义 | 低 |
| L-02 | validator | 单位检查为基本检查，仅对简单标识符型单位发出警告，复合单位（如 m^3/s）不做校验 | 低 |
| L-03 | validator | 引用检查无法区分类型名与实例名，对以大写开头的标识符默认为类型名不做未定义警告 | 低 |
| L-04 | compiler | GeoJSON 输出的几何信息依赖从文本中正则提取坐标，部分文件可能无几何信息 | 中 |
| L-05 | compiler | CityGML 输出为风格存根（stub），尚未包含完整 CityGML 3.0 Application Schema 定义 | 中 |
| L-06 | compiler | pipeline 描述符为自定义格式，尚未对接具体耦合框架（如 OMS、CSDMS）的标准 | 低 |
| L-07 | scene_builder | 模板为硬编码，不支持从现有 .cz 文件逆向导入为模板 | 低 |

### 7.2 未发现的缺陷

在本次测试范围内，未发现导致工具崩溃或产生错误输出的缺陷。所有工具在 6 个测试文件上均表现正常。

## 8 改进建议

| 优先级 | 建议 | 涉及工具 |
|:---:|:---|:---|
| 高 | 为 compiler 的 GeoJSON 输出增加空间参考系（CRS）声明字段，提升与 GIS 软件的互操作性 | compiler |
| 高 | 为 validator 增加更完整的跨行表达式解析能力，支持多行字符串和嵌套结构 | validator |
| 中 | 为 compiler 的 CityGML 输出补充完整 Application Schema，支持 LOD 0–4 | compiler |
| 中 | 为 compiler 的 pipeline 输出增加对 CSDMS BMI 接口标准的映射 | compiler |
| 中 | 为 scene_builder 增加 .cz 文件逆向导入功能，支持从现有文件生成可编辑模板 | scene_builder |
| 低 | 为 validator 增加 SEDRIS/CDB 兼容性检查模式 | validator |
| 低 | 为所有工具增加 --verbose 选项，输出调试信息 | 全部 |

## 9 测试结论

本次测试对 CZ-DSL 工具集的三个工具（场景构造器、内容校验器、系统编译器）进行了功能测试、兼容性测试和稳定性测试。测试结果表明：

1. **功能完备性**：三个工具均能按设计要求正常工作，场景构造器可生成含 原子构造关键字的 .cz/XML/JSON 文件，校验器能正确识别语法和语义问题，编译器可将 .cz 文件转换为四种目标格式。

2. **向后兼容性**：所有 6 个测试文件（涵盖 v1 的全部主要构造类型）均能被校验器和编译器正常处理，无崩溃或异常，满足向后兼容的设计目标。

3. **运行稳定性**：10 次重复运行结果一致，标准差低于 0.002s（排除冷启动），表明工具在当前测试规模下运行稳定可靠。

4. **性能表现**：单文件处理时间在 0.03–0.05s 范围内，满足交互式使用需求。

**总体评价：工具集通过全部测试项，可交付使用。**
