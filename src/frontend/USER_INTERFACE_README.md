# CZ-DSL 用户界面文档

## 概述

CZ-DSL 用户界面是一个现代化的Web应用程序，为海岸带建模提供完整的用户交互体验。该界面专注于实际使用场景，区别于管理后台，提供直观的工作流程和强大的功能。

## 主要功能

### 🏗️ 工作台 (Workspace)
- **代码编辑器**: 集成Monaco编辑器，支持CZ-DSL语法高亮
- **项目资源管理器**: 文件树结构，支持文件创建、编辑、删除
- **模型组件库**: 拖拽式模型组件，包括海洋、大气、波浪、沉积物模型
- **属性面板**: 实时编辑模型参数和边界条件
- **终端集成**: 内置终端支持CZ-DSL编译器命令
- **调试功能**: 断点调试、变量监控、执行控制

### 📁 项目管理 (Projects)
- **项目创建**: 支持多种项目模板（空白、海岸带、海洋、大气）
- **项目状态**: 实时显示项目运行状态
- **项目切换**: 快速在多个项目间切换
- **项目配置**: 灵活的项目设置和参数配置

### 🧩 模型库 (Models)
- **模型分类**: 按类型（海洋、大气、波浪、沉积物）筛选
- **模型评级**: 社区评分和下载统计
- **模型详情**: 完整的技术规格和使用说明
- **一键集成**: 直接添加到当前项目

### 📊 数据管理 (Data)
- **文件上传**: 支持拖拽上传，多种格式（NetCDF、CSV、GeoTIFF）
- **数据预览**: 内置数据查看器，支持表格和元数据显示
- **数据组织**: 按类型、日期、大小排序和筛选
- **数据操作**: 下载、删除、重命名等基本操作

### 📈 结果展示 (Results)
- **实时监控**: 模拟进度实时更新
- **结果可视化**: 内置图表和3D可视化组件
- **数据导出**: 多种格式导出（NetCDF、CSV、JSON、MATLAB）
- **结果分析**: 统计分析和对比功能

## 技术特性

### 🎨 现代化设计
- **响应式布局**: 适配桌面、平板、手机等多种设备
- **暗色主题**: 护眼的代码编辑环境
- **流畅动画**: 平滑的交互动画和过渡效果

- **模块化架构**: 清晰的代码结构，易于维护

## 快速开始

### 1. 启动测试服务器

```bash
cd frontend
python3 test_server.py
```

### 2. 访问界面

打开浏览器访问: http://localhost:8080/user_interface.html

### 3. 基本操作

1. **创建项目**: 点击"新建项目"按钮或项目视图中的新建卡片
2. **编写代码**: 在工作台中使用Monaco编辑器编写CZ-DSL代码
3. **添加模型**: 从模型库拖拽组件到工作台
4. **上传数据**: 在数据管理中上传所需的数据文件
5. **运行模拟**: 点击运行按钮执行模型
6. **查看结果**: 在结果视图中查看和分析输出

## 支持的文件格式

### 数据文件
- **NetCDF** (.nc): 科学数据标准格式
- **CSV** (.csv): 逗号分隔值文件
- **GeoTIFF** (.tif): 地理空间栅格数据
- **JSON** (.json): JavaScript对象表示法
- **TXT** (.txt): 纯文本文件

### 代码文件
- **CZ-DSL** (.cz): CZ-DSL源代码文件
- **Python** (.py): Python脚本文件
- **JavaScript** (.js): JavaScript文件
- **JSON** (.json): 配置文件

## 性能建议

### 系统要求
- **内存**: 最少4GB，推荐8GB+
- **处理器**: 双核2GHz+，推荐四核3GHz+
- **存储**: 最少1GB可用空间
- **网络**: 宽带连接（用于模型下载）

### 优化建议
1. **关闭不必要的标签页**: 释放内存资源
2. **定期清理缓存**: 保持浏览器性能
3. **使用最新浏览器**: 获得最佳性能和安全性
4. **启用硬件加速**: 提升图形渲染性能

## 故障排除

### 常见问题

**Q: 编辑器无法加载？**
A: 检查网络连接，Monaco编辑器需要从CDN加载资源。

**Q: 文件上传失败？**
A: 检查文件大小和格式，确保符合支持的类型。

**Q: 代码运行没有响应？**
A: 检查代码语法，查看终端输出的错误信息。

**Q: 界面显示异常？**
A: 尝试刷新页面，清除浏览器缓存。

### 调试模式

在浏览器开发者工具中，可以查看详细的调试信息：

1. 按 `F12` 打开开发者工具
2. 查看 Console 标签页的错误信息
3. 在 Network 标签页检查网络请求
4. 使用 Sources 标签页调试JavaScript代码

## 开发指南

### 代码结构

```javascript
class CZDSLUserInterface {
    constructor()           // 初始化
    setupNavigation()       // 导航设置
    setupWorkspace()        // 工作台设置
    setupProjects()         // 项目管理
    setupModels()          // 模型库
    setupData()            // 数据管理
    setupResults()         // 结果展示
    setupModal()           // 模态对话框
    showNotification()     // 通知系统
}
```

### 样式系统

使用CSS自定义属性（CSS Variables）实现主题系统：

```css
:root {
    --primary-color: #2563eb;
    --surface: #ffffff;
    --text-primary: #1e293b;
    /* ... 更多变量 */
}
```
