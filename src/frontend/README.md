# CZ-DSL 前端展示

这是CZ-DSL（海岸带复杂系统建模语言）的网页前端展示界面。

## 🚀 快速开始

### 启动服务器

```bash
# 进入前端目录
cd frontend

# 启动HTTP服务器（默认端口8000）
python3 server.py

# 或指定端口
python3 server.py 8080
```

### 访问界面

打开浏览器访问：http://localhost:8080

## 📋 功能特性

### 1. 项目概览
- 显示CZ-DSL项目的整体进度
- 各模块完成状态（词法分析器、语法分析器、语义分析器、代码生成器）
- 功能特性展示

### 2. 在线编辑器
- 实时代码编辑
- 模拟解析功能
- 词法分析结果展示
- 语法分析结果展示
- 错误提示和建议

### 3. 示例代码
- 基础球层定义示例
- 物理过程建模示例
- AI模型集成示例
- 一键加载到编辑器

### 4. 语言特性
- 多语言支持（中英文关键字）
- 物理单位系统
- AI原生集成

### 5. AST可视化
- 抽象语法树结构展示
- 实时AST生成
- 节点类型和值显示

## 🛠️ 技术实现

### 前端技术栈
- **HTML5**: 页面结构
- **CSS3**: 样式和动画
- **JavaScript (ES6+)**: 交互逻辑
- **Prism.js**: 语法高亮

### 核心功能
- **模拟解析器**: 基于JavaScript实现的CZ-DSL解析模拟
- **词法分析**: 识别关键字、标识符、数字、字符串、单位等
- **语法分析**: 生成简化的AST结构
- **错误处理**: 基础的语法错误检测

### 响应式设计
- 支持桌面和移动设备
- 自适应布局
- 触摸友好的交互

frontend/
